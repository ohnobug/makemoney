# Publisher Pages - 发布页面模块

## 页面列表

### 1. viga_publisher_page.dart - 主发布页面
- **功能**: 选择AI创作或上传原创作品
- **特色**:
  - 现代化卡片布局
  - 右上角弹出菜单功能 ✨
  - 费用说明区域

#### 弹出菜单功能
点击右上角图标按钮，会弹出以下菜单选项：
- **发布历史**: 查看已发布的作品历史
- **草稿箱**: 查看和管理草稿
- **发布设置**: 配置发布相关设置
- **帮助与反馈**: 获取帮助和提供反馈

### 2. viga_publish_work_page.dart - 作品发布页
- **功能**: 发布作品的详细页面
- **特色**:
  - 素材预览和选择
  - 标题和描述输入
  - 位置和可见性设置

### 3. viga_ai_publisher_page.dart - AI创作页面
- **功能**: AI图像生成创作
- **特色**:
  - LoRA模型选择和权重调节
  - 提示词输入
  - 一键生成功能

### 4. viga_resource_publisher_page.dart - 灵感库页面
- **功能**: 浏览和选择创作灵感模型
- **特色**:
  - 模型搜索功能
  - 网格布局展示
  - 作者信息显示

### 5. viga_geolocator_page.dart - 位置选择页面
- **功能**: 选择作品发布位置
- **特色**:
  - 城市标签切换
  - 位置搜索功能
  - 距离显示

### 6. viga_visible_pop_up.dart - 可见性设置页面
- **功能**: 设置作品可见性权限
- **特色**:
  - 多种可见性选项
  - 底部弹窗设计

## 设计特点

- 🎨 **统一设计语言**: 采用Material Design 3设计系统
- 💎 **现代化UI**: 卡片式布局，优雅阴影效果
- 🌈 **品牌色彩**: 使用紫色系作为主色调
- 📱 **响应式设计**: 支持不同屏幕尺寸
- ✨ **流畅交互**: 统一的动画和反馈效果

## 技术实现

- **状态管理**: 使用Flutter BLoC模式
- **导航路由**: 集成应用路由系统
- **国际化**: 支持多语言切换
- **主题系统**: 支持明暗主题切换
- **屏幕适配**: 使用flutter_screenutil进行尺寸适配
