## 第三章 核心思想

用多链构建一个区块链森林，奠基元宇宙。

产品的核心概念是：**一人一链**、**一群一链**、**一机万链**、**万链互联**。



### 3.1、角色划分

在理解这些概念之前，需要先理清楚这款产品的不同角色。

| 角色       | 介绍                                                     |
| ---------- | -------------------------------------------------------- |
| 自然人     | 一个有生命的人类。                                       |
| 公司或机构 | 一个由多人组成的公司主体。（较于一个自然人来说更加权威） |
| 账号       | 由人类、或公司机构创建的 全球唯一的账号。                |
| 服务器     | 可提供算力、存储、网络的机器。                           |
| 大节点     | 提供包括区块链、AI、文件存储等的多种不同功能的节点。     |
| 权威大节点 | 与大节点没区别，只是社会地位较大节点来说更加高。         |



### 3.2 一人一链

一人一链 怎么听起来像有中心化？其实不然，一人一链是站在 **自然人** 的角度来说的，而站在 **节点** 角度仍然是去中心化的。

如何实现呢？我用现实生活中的交朋友来进行类比，假如有自然人：A、B、C、D。

| 谁   | 朋友    | 说明                       |
| ---- | ------- | -------------------------- |
| A    | B、C、D | 站在A的角度、他认识B、C、D |
| B    | A       | 站在B的角度、他认识A       |
| C    | A、D    | 站在C的角度、他认识A、D    |
| D    | A、C    | 站在D的角度、他认识A、C    |

基于上方表格，假设这些自然人分别都有属于自己的节点，那么:

| 链   | 运作节点   | 说明                                                 |
| ---- | ---------- | ---------------------------------------------------- |
| A链  | A、B、C、D | 由A用户创建，并且A用户拥有100%的Token的链，命名为A链 |
| B链  | A、B       | 由B用户创建，并且B用户拥有100%的Token的链，命名为B链 |
| C链  | A、C、D    | 由C用户创建，并且C用户拥有100%的Token的链，命名为C链 |
| D链  | A、C、D    | 由D用户创建，并且D用户拥有100%的Token的链，命名为D链 |

类似一个笛卡尔积的表格。



此处会产生疑问：用户自行创建的链，并且拥有100%Token，那其他朋友对于我来说，共识的意义是？

答案：因为我是他们的朋友，所以这种关系需要共识。



正如聊天工具，他是我的朋友所以他存在于我的好友列表一样，不是好友则删除掉。
同理，由于他是我的好友，所以我参与好友的链，帮助他的链共识，不是我的好友则退出该链。

（这种加入退出链的操作对于用户来说是无感的，就像删除好友添加好友一样便捷，一切都是授权大节点来实现。）



关于建链时候的Token数量可以用黄金价值来理解：不能说我没有黄金，所以黄金不值钱。而是说黄金很值钱，只是我没有。

因此，如果A、B、C、D都站在自己的角度来看，则会有不同的朋友圈子，这些圈子则可以成为一条区块链，随着朋友的数量越来越多，这个链会越来越可靠。

可能有些读者觉得难以理解😵，那我换种方式说明一下：在比特币诞生的时候，中本聪用自己的电脑挖了很多比特币，到目前为止，他持有 **约一百万个比特币** 。但是可以说，因中本聪持有非常多的比特币，而说比特币的共识网络是中心化或者不安全、不可靠吗？显然不能。

区块链的本质是一个去中心化的数据库，拥有Token的人只能说明他有进行转账交易的权力，而节点的功能则是见证这些交易和校验这些交易，起到共同监督、不被破坏这个数据库的作用。

因此好友则代表节点越多，监督的人就越多，这个链就越可靠。



### 3.3、一群一链

一群一链的概念与一人一链的概念十分类似，围绕的是群的主题。

假如我喜欢迈克尔杰克逊，我创建了一个群：迈克尔粉丝群，那么会有其他同样喜欢迈克尔加入到这个群，这群人都是围绕着一个“喜欢迈克尔杰克逊”共识而聚到一起，而不是因为钱。

而我为了更好的维护这个圈，将创建时持有的100%Token，在创群之初按照某种规则转账给群友（平均 或者 按照某种贡献），将权力下发，群友按照可以按照自身持有的Token多少进行质押投票选举群管理员，赋予群管理员一些特殊的权限。详细功能，我将会在后续介绍。



### 3.4、一机万链

得益于Docker容器技术的发展，使用一台服务器就可以轻松的实现多个容器同时运行。因此一台服务器可以创建多个数据隔离、算法隔离的链，而互不干涉，这也是一机万链的实现原理。

值得注意的是：本产品一机万链的实现只有一个Web出口，可以用Nginx来实现反向代理，用户进入节点可通过参数选择不同的链进行交互。



### 3.5、万链互联

万链互联的本质就是跨链交互，从自然人的角度来看，正所谓一个好汉三个帮，帮与帮需要介质来交换价值，就如国与国之间需要货币兑换一样。



了解 **一人一链**、**一群一链**、**一机万链**、**万链互联** 这些原理是实施 **Metaverse entrance** 的关键。

## 第四章 大节点范式

​	为实现本产品的特定功能，我们在此引入并阐述 **大节点** 的概念。与传统区块链网络中一个节点通常只承载单一链服务的模式不同，大节点被设计为提供更为丰富和多样的功能，以全面满足产品层面的复杂需求。

​	现有的人类使用互联网的方式，基本上都是手机。在手机这种边缘设备上运行一个大节点显然不能满足需求。

​	因此作为使用者需要委托 算力更强、网络更快、存储空间更大的 大节点来服务。

​	大节点也因为提供优质的服务，并以此来收取租赁费用。这是合理的，有益于用户而取得的收益。



### 4.1 安全问题

​	用户委托大节点而建立的区块链是否存在安全问题？

​	不会



### 4.2 大节点的使用权与付费机制

与Pow共识不同，以往的节点的都是以挖矿的方式而导致大量的电能浪费。

因此本产品转变为因提供服务而消耗电源，这是有益的改变。

| 方面               | 说明                                                         |
| ------------------ | ------------------------------------------------------------ |
| 部署与服务提供     | 大节点支持用户自行搭建和部署，搭建成功后，其可以作为服务提供者向其他用户输出服务。 |
| 使用费用与计费模式 | 用户若需使用大节点提供的各项服务，需要向大节点运营方支付相应的**租赁费用**。这种费用通常以**月租**的形式收取，以提供固定的服务流量和使用时长。 |
| 为何采用流量计费   | 选择以**流量**作为主要的计费依据，是基于大节点设计的核心特性：用户的具体数据内容对于节点运营者而言是**加密且不可见**的。因此，通过测量和收取数据传输的流量费用，成为一种公平且可行的计费方式，能够有效地衡量用户对节点资源的使用量，而不侵犯用户的数据隐私。 |



### 4.3、存储系统

大节点需要提供文件存储服务，由于IPFS存在某些弊端和复杂性。
改为轻便的使用方式：即用户上载文件是免费的，但是下载会扣除流量费用。

上载文件 大节点的存储服务会保留30天，若无人下载，则该文件将自动清理。

（如聊天群，用户发一个视频，多人观看，那么这种方式可以增加节点的收入。）



是否会存在节点作恶，下载的文件不是想要的？

会存在，但是客户端会校验由谁发出，若作恶节点替换文件内容，内容将会存在打不开的情况。

用户也会因为节点的不可靠而更换节点，大节点也会导致客户流失。



### 4.4、建链系统

用户在租赁大节点的情况，大节点提供建链服务。

用户建链：用户注册账号时，由于用户资料是去中心化的，因此建链后，用户资料会存于自建链的合约上，后续用户基本资料可由用户更新，并且是有版本的更新。

用户的自己加的好友，待好友同意后，好友所委托的节点需与用户节点达成区块共识。

建群会建一个链。

开发者发行小程序亦会建一个链与使用者共同维护。。



### 4.5、内容审查系统

由于加密内容是不可控的，某些暴力色情的内容并不为大众所喜，因此大节点会提供AI内容过滤服务。

若用户收到非法信息，可以提交进行投诉，由大模型进行内容审核，定位恶意资料，进行删除，并且标记恶意用户，通知其他节点共同封杀。

为了实现实时性，利用端侧大模型对内容进行审查，实时过滤非法资料的展示。



### 4.6、证书颁发系统

证书的目的是为了增强用户自身的可信度。

用户可基于现实身份，去权威大节点获取证书。

所谓权威大节点与用户搭建的大节点无什么不同，区别就是权威大节点在社会地位上较普通用户搭建的大节点更加权威。



这个证书将互相保存，作为用户的凭证。

举个例子：

​	我是Tiktok的大网红，但是我需要让链上的人也知道我是大网红，则我需要拿出由Tiktok颁发给我的证书，证明大网红的Tiktok账号是我。

​	我刚读完大学，我需要证明我是大学生，可以展示由 大学这个权威大节点颁发的 证书。



​	一个自然人会在各种机构获得不同的证书，这些证书是为了更好的在元宇宙世界里面定位你是你，让其他用户可以更方便的在元宇宙上确认你是你，而不是骗子。



### 4.7、提供信源

​	大节点拥有在朋友圈打广告的权利，拥有内容推荐的权利，当然用户可以屏蔽，或者选择其他信源。
